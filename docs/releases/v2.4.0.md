# BDO-AIO v2.4.0 - Axis-aware body sliders

This release replaces the old Baseline/Recommended/High/Extreme body-size menu with a simpler **Recommended** or **Custom** workflow.

## Recommended ceilings

- Breasts: X/Y/Z **1.55**
- Thighs: Y/Z **1.35**; X leg length untouched
- Butt cheeks: X/Y/Z **1.20**
- Front pelvis/groin: Y/Z **1.40**; X length untouched
- Belly/lower back: X **1.28**, Z **1.45**; Y untouched

Custom exposes every supported axis independently. The launcher explains that breast X is length/forward projection, Y is width, and Z is height. It also explains the uneven observed stock limits (X 1.30 and Y/Z 1.55) and includes balanced and equal-additive examples without claiming one ratio is universally correct.

## Upgrade and safety

- Existing Custom configurations migrate automatically to schema 2.
- Old Belly scalar values migrate to Belly Z only; the new Spine-X exception is never enabled accidentally.
- Only `Max` is changed. `Min` and `Default` remain untouched.
- Limits are widen-only and every descriptor keeps its exact byte length.
- Belly X is an intentional `HeightAxis` exception that can lengthen the lower torso and shift the groin downward.
- Restore vanilla once before testing exact Recommended values if a previous injection used breasts above 1.55 or widened Belly Y. Keeping or raising the same ceilings does not require restoration.

## Validation

A read-only audit processed all 75 live customization descriptors in memory: 3,136 target tags, 2,383 Max edits, and zero byte-length, Min, Default, protected-axis, or widen-only violations.

Automated validation does not prove appearance on every class or outfit. Please report class-specific deformation or clipping with the class, region, axis values, and outfit used.
