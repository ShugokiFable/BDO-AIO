# BDO-AIO v2.4.1 - Body slider controls and wording hotfix

This release includes all body-slider work since v2.3.0 plus the v2.4.1 wording correction.

## Body slider workflow

- Replaced Baseline/High/Extreme with **Recommended**, **Custom**, and **Keep current**.
- Added 12 independent Max ceilings for breasts, thighs, butt cheeks, front pelvis/groin, and belly/lower back.
- Recommended: breasts X/Y/Z 1.55; thighs Y/Z 1.35; butt cheeks X/Y/Z 1.20; pelvis Y/Z 1.40; belly X 1.28 and Z 1.45.
- Thigh X, pelvis X, and belly Y remain protected.
- Breast help explains X projection/length, Y width, Z height, stock X 1.30 versus Y/Z 1.55, and proportional test examples.

## Clarified butt and pelvis controls

- **Butt cheeks** changes cheek shape/roundness, not total ass size.
- **Front pelvis/groin Z (`pelvis.z`)** is the main overall pelvis/ass-size control and affects the front groin and rear.

## Safety and migration

- Only `Max` is patched; `Min` and `Default` remain untouched.
- Patching is widen-only and preserves exact descriptor byte length.
- Existing schema-1 Custom settings migrate automatically; old Belly values never silently enable Belly X.
- Restore once only when testing exact Recommended ceilings after previously injecting higher values.
