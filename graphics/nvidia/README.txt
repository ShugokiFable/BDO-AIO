BLACK DESERT - NVIDIA PROFILE INSPECTOR (.nip)
==============================================

File
  Black_Desert_Max_Quality.nip

What it does
  Imports a "Black Desert" driver profile for blackdesert64.exe with
  max-quality style settings, for example:
  - Preferred refresh rate
  - Power management: Prefer maximum performance
  - Anisotropic filtering / texture filtering quality
  - Shader cache enabled
  - Negative LOD bias clamp style settings

How to apply (easiest)
  1. Close Black Desert
  2. Open BDO-AIO -> START.bat -> press N
  3. Confirm import (uses bundled tools\nvidiaProfileInspector or your install)

Manual apply
  1. Run nvidiaProfileInspector.exe
  2. Import profiles -> select Black_Desert_Max_Quality.nip
  3. Apply / save changes

Notes
  - NVIDIA GPU + Game Ready / Studio driver required
  - Does NOT replace GameOption.txt (use menu G for that)
  - After big driver updates, re-import if settings reset
